# Contributing to Termix

Thanks for your interest in contributing.

## Getting started

1. Fork the repository.
2. Create a branch for your change.
3. Install dependencies with `npm install`.
4. Test your change locally.

## Development workflow

- Keep pull requests focused on a single topic.
- Prefer clear commit messages.
- Update relevant documentation when behavior changes.

## Pull request checklist

- [ ] Code builds successfully (`npm run build`)
- [ ] Related behavior is tested manually
- [ ] Documentation updated (if needed)
- [ ] No sensitive information included

## Reporting bugs and requesting features

Please use GitHub Issues and include enough detail to reproduce the problem or explain the proposal.
